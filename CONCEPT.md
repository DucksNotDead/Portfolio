# Концепция сайта-визитки

Статус: план перед реализацией. Репозиторий: `portfolio` (публичный, отдельно от HeadHealer).

Источники контента (пока в соседнем репо HeadHealer): `resume.md`, `experience-story.md`, диалог с обсуждением концепции.

Референс по структуре и UX: [predein.com](https://predein.com/) — одностраничный лендинг, секции через якоря в шапке, стек выпадашками, флагманский кейс отдельно от сетки остальных проектов, переключатель темы в шапке.

---

## 1. Цель и позиционирование

Сайт должен «продавать» автора как разработчика: убеждать и рекрутёра, и технического интервьюера за 30-60 секунд просмотра, при этом давать глубину для тех, кто готов копать дальше.

Главный месседж: инженер, который берёт проблемные/сложные системы и доводит их до результата, а не просто закрывает тикеты. Опорные факты для этого месседжа:

- Поднял покрытие тестами с 5% до 73% (АС «Интегрированная система пропуска»), устранив хаос в code review.
- В кризис на ЕГИС ОТБ переделал вместе с командой около 80% готового портала за месяц из-за резко изменившихся бизнес-требований, проект сдан в срок.
- Реализовал офлайн-кэш для GraphQL (XOLOGIE) без прямых готовых решений на рынке, тема стала дипломом, защищённым на 5.
- 4-кратный победитель IT-чемпионата «Цифровая Эра Транспорта».

Второй слой месседжа: любопытство и рост, самостоятельный путь до fullstack на федеральных гос. системах, осознанное использование AI-инструментов для ускорения разработки (~4x на типовых модулях).

## 2. Аудитория и язык

Билингвальный сайт, RU/EN с переключателем. RU — основной трафик (hh.ru и русскоязычные рекрутёры), EN — под remote/международные вакансии (английский на уровне B2-C1, это тоже часть продажи себя).

---



## 3. Карта сайта

Одностраничный скролл-лендинг (`/`). Навигация в шапке — якоря по секциям. Отдельных маршрутов `/projects`, `/stack` и т.п. нет.

Секции:

1. **Hero**: имя, роль, ключевой месседж-позиционирование, кнопки «Скачать резюме (PDF)» и переход к контактам, ссылки (GitHub, Telegram, email).
2. **Обо мне**: короткий личный текст, фото/факты с хакатонов «Цифровая Эра Транспорта».
3. **Образование**: ИРНИТУ, тема диплома (PWA/офлайн-режим), защита на 5, фото защиты, связка с кейсом XOLOGIE.
4. **Проекты**:
  - флагманский кейс (XOLOGIE) — развёрнутый блок на странице (Проблема → Решение → Результат), не карточка;
  - остальные проекты — сетка карточек (превью, стек, 2-3 буллета, ссылки демо/код при наличии).
5. **Стек и инструменты**: категории технологий в выпадашках (accordion), плюс отдельная выпадашка/блок про AI-workflow (Cursor, ускорение разработки). По аналогии с блоком «С чем работаю» на референсе.
6. **Контакты / футер**: прямые ссылки, копирайт, ссылка на репозиторий сайта.

Шапка: лого/имя, якоря секций, переключатель RU/EN, переключатель темы.

---



## 4. Раздел «Проекты»

Два формата на одной странице:

- **Флагманский case-study (in-page)**: XOLOGIE (offline-first PWA поверх GraphQL). Полная история прямо в секции: проблема кэширования POST-запросов, кастомный Service Worker, результат (2x ускорение разработки второго продукта), связь с дипломом и победой на хакатоне.
- **Остальные проекты — карточки**: компактные превью без отдельных страниц. Новые pet-проекты добавляются как записи в контент-файле (`content/projects.ts` / MDX-фрагменты), без переделки дизайна.

---



## 5. Визуальный язык и тема

Светлая и тёмная темы с техно-эстетикой: монохромные UI-элементы, точечные акценты в духе кода/терминала, курсор, мигающий как в терминале, тонкие рамки в стиле code-editor. Моноширинный шрифт (JetBrains Mono / Fira Code) для технических деталей и акцентов, обычный читаемый шрифт для основного текста.

Тема:

- по умолчанию следует системным настройкам устройства (`prefers-color-scheme`);
- в шапке — ручной переключатель (как на [predein.com](https://predein.com/));
- выбор пользователя сохраняется (localStorage), пока не сброшен.

---



## 6. Технический стек

- **Next.js + TypeScript** (App Router), по сути одна страница + статика.
- **Tailwind CSS** для вёрстки.
- Контент проектов и стека — в `content/*.ts` (или лёгкий MDX для длинного кейса XOLOGIE), без мультироутинга.
- **next-intl** (или встроенный i18n) для переключателя RU/EN.
- Тема: CSS variables + `next-themes` (system / light / dark).
- **Framer Motion** для лёгких микроанимаций (раскрытие accordion стека, появление секций).
- **GitHub REST API** с ISR-кэшированием для виджета активности (contribution-style, топ-репозитории) — без превышения rate limit.
- Статический **резюме.pdf** в `public/`, ссылка в hero и футере.
- Хостинг: уже есть, домен `dev.holuenko.ru`. Деплой под существующую инфраструктуру (не привязываться к Vercel как к обязательству).
- Аналитика: обсудить отдельно, если нужно вообще.
